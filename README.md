🔗 URL Shortener Backend Service

A robust and scalable backend system powering a full-stack URL shortening platform. Built with Node.js, Express, and MongoDB, this service is designed to efficiently generate, manage, and track shortened URLs with secure authentication and analytics capabilities.

---

🚀 Project Overview

This backend serves as the core engine of the URL Shortener application, handling URL generation, redirection logic, user authentication, and analytics tracking. It is architected to ensure performance, scalability, and secure data handling.

---

## ⚙️ Key Features

- ⚡ High-performance URL shortening engine with unique ID generation
- 🔁 Seamless redirection from short URLs to original destinations
- 📊 Advanced analytics tracking (click counts & visit history)
- 🔐 Secure authentication system using JWT-based authorization
- 🧱 Middleware-protected API routes for enhanced security
- 🚦 Rate limiting to prevent API abuse and ensure stability

🛠️ Tech Stack

- Node.js (Runtime Environment)
- Express.js (Backend Framework)
- MongoDB Atlas (Cloud Database)
- Mongoose (ODM)
- JSON Web Token (Authentication)
- CORS (Cross-Origin Resource Sharing)
